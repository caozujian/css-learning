Git 和 GitHub 第 1 课

1. Git 和 GitHub 的区别

  • Git：安装在电脑上的版本控制工具。
  • GitHub：在线保存 Git 仓库、展示项目和协作的平台。

2. 常用工作流

git status
git add .
git commit -m "完成 JavaScript 第 6 课"
git log --oneline

修改文件后，先用 status 查看变化，再用 add 暂存，最后用 commit 保存一个版本。

3. 初始化当前学习项目

在 PowerShell 中执行以下命令。路径中的反斜杠适用于 Windows：

cd "D:\Study\PythonNote\web\css-learning"
git init
git status
git add .
git commit -m "开始学习网页开发"

4. 设置 Git 身份

如果提交时提示没有用户名或邮箱，只需设置一次：

git config --global user.name "你的名字"
git config --global user.email "你的邮箱"

邮箱建议使用你 GitHub 账号中已验证的邮箱。

动手任务

  1. 初始化当前 css-learning 文件夹。
  2. 创建第一个 commit。
  3. 运行 git log --oneline，确认能看到提交记录。
  4. 修改任意一个 HTML 文件，再次执行 git status。

记住这四个词

  • working tree：你正在编辑的文件。
  • staging area：通过 git add 准备提交的文件。
  • commit：保存的版本节点。
  • repository：Git 仓库。
