JavaScript 第 3 课：DOM 操作

DOM（文档对象模型）会把 HTML 页面转换成 JavaScript 可以操作的对象。

1. 选中元素

const title = document.querySelector("h1");
const message = document.querySelector("#message");

querySelector 使用 CSS 选择器查找第一个匹配的元素。

2. 修改内容和样式

message.textContent = "文字已经被修改";
message.style.color = "green";

推荐使用 textContent 修改文字，不要把用户输入直接放进 innerHTML。
