JavaScript 第 6 课：异步请求和 API

1. 什么是 API

API 是程序之间沟通的接口。网页可以向服务器请求数据，服务器再返回 JSON 格式的结果。

2. 使用 fetch 请求数据

async function loadData() {
    const response = await fetch("https://jsonplaceholder.typicode.com/posts/1");
    const data = await response.json();
    console.log(data);
}

await 会等待异步操作完成。请求失败时，可以使用 try...catch 显示错误。
