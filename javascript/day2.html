JavaScript 第 2 课：判断、数组和循环

1. 条件判断

const score = 85;

if (score >= 60) {
    console.log("及格了");
} else {
    console.log("还要继续努力");
}

比较常用的运算符：>、<、===、&&（并且）、||（或者）。

2. 数组

const skills = ["HTML", "CSS", "JavaScript"];

console.log(skills[0]); // 第一个元素
console.log(skills.length); // 数组长度
skills.push("Git"); // 添加元素
console.log(skills);

3. 循环

const skills = ["HTML", "CSS", "JavaScript"];

for (const skill of skills) {
    console.log(`我正在学习 ${skill}`);
}
