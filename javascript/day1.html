JavaScript 第 1 课：让网页动起来

1. 输出内容

打开浏览器开发者工具（按 F12），切换到 Console（控制台）标签页。

console.log("你好，JavaScript！");
console.log(2 + 3);

2. 变量与数据

const name = "小明"; // 不会重新赋值的变量
let age = 18;       // 可以重新赋值的变量
age = age + 1;

const isLearning = true; // 布尔值：true 或 false
console.log(name, age, isLearning);

常见数据类型：字符串、数字、布尔值。使用 typeof 可以查看类型。

3. 运算与函数

function introduce(person, personAge) {
    return `我叫${person}，今年${personAge}岁。`;
}

const message = introduce("小明", 19);
console.log(message);
