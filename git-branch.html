Git 分支与合并

1. 为什么使用分支

分支可以让你在不影响稳定版 main 的情况下开发新功能。功能完成并检查后，再合并回主分支。

2. 常用命令

git branch                 # 查看本地分支
git switch -c feature-note # 创建并切换到新分支
git add .
git commit -m "添加分支练习"
git switch main            # 切回主分支
git merge feature-note     # 合并功能分支
git branch -d feature-note # 删除已合并的分支

3. 推送分支

git push -u origin feature-note
git push

远程分支可以用于备份，也可以发起 Pull Request，让别人审查代码后再合并。

动手任务

  1. 先保存当前课程页：git add .，提交并推送到 main。
  2. 创建分支：git switch -c feature-note。
  3. 修改一个 HTML 文件，提交并推送这个分支。
  4. 在 GitHub 上查看分支，并创建 Pull Request。
  5. 合并 Pull Request 后，在本地执行 git switch main 和 git pull。

遇到冲突怎么办

Git 会标记冲突文件。手动保留正确内容后，执行：

git add 冲突文件名
git commit -m "解决合并冲突"
