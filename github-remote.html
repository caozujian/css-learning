GitHub 远程仓库

1. 创建 GitHub 仓库

  1. 登录 GitHub，点击右上角 +，选择 New repository。
  2. 仓库名填写：css-learning。
  3. 选择 Public 或 Private。
  4. 不要勾选 README、.gitignore 或 License，因为本地已经有 Git 提交。
  5. 点击 Create repository。

2. 连接本地仓库

把下面的地址替换成你自己的 GitHub 用户名和仓库名：

cd "D:\Study\PythonNote\web\css-learning"
git remote add origin https://github.com/你的用户名/css-learning.git
git remote -v

3. 推送代码

git branch -M main
git push -u origin main

第一次推送可能会打开浏览器要求登录 GitHub。请使用 GitHub 官方登录流程，不要把密码或 Token 粘贴给任何人。

4. 以后同步代码

git add .
git commit -m "描述这次修改"
git push

动手任务

  1. 在 GitHub 创建空仓库。
  2. 添加 origin 远程地址。
  3. 将 main 分支推送到 GitHub。
  4. 刷新 GitHub 仓库页面，确认能看到 JavaScript 和 Git 课程文件。

安全提醒：不要把密码、Personal Access Token、API Key 写进代码或发到聊天中。
