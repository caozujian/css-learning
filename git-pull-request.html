Pull Request 与冲突处理

1. Pull Request 是什么

Pull Request（PR）是请求把一个分支的修改合并到另一个分支，通常会先进行代码审查和自动检查。

2. 创建并推送功能分支

git switch main
git pull
git switch -c feature-profile

# 修改文件后
git add .
git commit -m "添加个人简介功能"
git push -u origin feature-profile

推送后，在 GitHub 打开仓库，点击 Compare & pull request，目标分支选择 main。

3. 合并 PR 后同步本地

git switch main
git pull
git branch -d feature-profile

4. 发生冲突时

如果两个分支修改了同一处内容，Git 会提示冲突。打开冲突文件，处理这些标记：

<<<<<<< HEAD
main 分支的内容
=======
feature 分支的内容
>>>>>>> feature-profile

保留正确内容并删除标记，然后执行：

git add 冲突文件名
git commit -m "解决合并冲突"

如果发现合并方向不对，还没有解决文件时，可以取消合并：

git merge --abort

动手任务

  1. 创建 feature-profile 分支。
  2. 在任意 HTML 页面添加一行内容并提交。
  3. 推送分支并在 GitHub 创建 Pull Request。
  4. 合并 PR 后，本地执行 git pull。
